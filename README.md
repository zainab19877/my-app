# 🎁 منظم الهدايا والمناسبات

تطبيق عربي سهل الاستخدام من الهاتف، يساعد العائلة والأصدقاء على تذكّر المناسبات واختيار الهدية المناسبة وإدارة الميزانية — **بدون إنشاء حساب**.

## المزايا
- **الأشخاص**: إضافة الأشخاص مع صلة القرابة (الأم، الأب، الأخ، الأخت، الزوج، الزوجة، الابن، الابنة، الجد، الجدة، صديق، صديقة، زميل عمل…) وملاحظات عن اهتماماتهم.
- **المناسبات**: عيد ميلاد، تخرج، زواج، أو مناسبة أخرى، مع التاريخ وميزانية لكل مناسبة. أعياد الميلاد تتكرر سنوياً تلقائياً.
- **التذكير قبل أسبوع**: تنبيه بارز في الصفحة الرئيسية، وإشعارات من المتصفح، وزر «أضف للتقويم» يضيف المناسبة لتقويم الهاتف مع تنبيه قبل 7 أيام.
- **اقترح هدية**: اختر الشخص ونوع المناسبة وأدخل الميزانية، فيعرض التطبيق 3 اقتراحات على الأقل تناسب **صلة القرابة** والمناسبة والميزانية، مع زر «اقتراحات أخرى».
- **سجل الهدايا السابقة**: قسم في الصفحة الرئيسية يحفظ الهدايا التي قُدّمت لكل شخص (من المناسبات أو بتسجيل يدوي لهدايا قديمة)، ويستبعدها تلقائياً من الاقتراحات حتى لا تتكرر.
- **الميزانية**: تسجيل تكلفة كل هدية، حساب المجموع والمتبقي، وتنبيه واضح عند تجاوز الميزانية.
- **العملة**: الدينار الأردني (د.أ).
- **نسخ احتياطي**: تصدير واستيراد البيانات لنقلها بين الأجهزة.
- يعمل بدون إنترنت ويمكن تثبيته على الشاشة الرئيسية كتطبيق.

> البيانات تُحفظ على جهازك فقط.

## التشغيل محلياً
```bash
python3 -m http.server 8000
```
ثم افتح `http://localhost:8000`.

## النشر برابط دائم (GitHub Pages)
1. من صفحة المستودع على GitHub: **Settings ← Pages**.
2. في **Source** اختر الفرع، والمجلد `/ (root)`، ثم **Save**.
3. بعد دقيقة يظهر رابط التطبيق. افتحه من الهاتف ثم اختر «إضافة إلى الشاشة الرئيسية».

## الملفات
| الملف | الوصف |
|---|---|
| `index.html` | هيكل الصفحة |
| `styles.css` | التصميم والألوان (مع الوضع الداكن) |
| `app.js` | منطق التطبيق |
| `gifts.js` | قاعدة اقتراحات الهدايا وأسعارها |
| `sw.js`, `manifest.json`, `icon*` | التثبيت على الهاتف والعمل بدون إنترنت |
